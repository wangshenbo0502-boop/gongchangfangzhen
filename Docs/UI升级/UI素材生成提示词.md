# UI 素材生成与交付说明

适用项目：工业车间设备三维可视化监控与交互巡检系统。风格为石墨灰工业专业风，主色 `#11151B`、面板 `#1A1E24`、强调色 `#E8B75C`。本文件只提供素材制作任务，不代表图片已生成或已接入。

返回：[UI 升级指导书](../../UI升级指导书.md)

## 1. 最值得先做的素材

优先做四张统一设备封面。由于项目已有精细三维模型，直接在 Unity/Blender 渲染最稳妥。外部生成主要用于欢迎插图、空状态插图和构图参考；设备图若使用生成工具，应输入当前真实模型截图并严格保形。

| 文件名 | 内容 | 推荐尺寸/格式 | 数量 |
| --- | --- | --- | --- |
| `device-p01-cover.png` | 循环水泵 | 1200×900 PNG | 1 |
| `device-tk01-cover.png` | 工艺储罐 | 1200×900 PNG | 1 |
| `device-f01-cover.png` | 车间排风机 | 1200×900 PNG | 1 |
| `device-plc01-cover.png` | 控制柜 | 1200×900 PNG | 1 |
| `assistant-welcome.png` | 工业知识助手欢迎插图 | 1024×768 透明 PNG | 可选 1 |
| `empty-orders.png` | 暂无工单 | 640×480 透明 PNG | 可选 1 |
| `empty-documents.png` | 暂无资料 | 640×480 透明 PNG | 可选 1 |

透明背景必须有真实 alpha 通道，不能把灰白棋盘格绘入图片。保留原始大图，再导出实际使用尺寸。不要把多个素材拼成一张无法单独使用的展示海报。

## 2. 四台设备封面提示词

使用时附上对应设备的现有模型截图。先完成水泵一张，固定镜头、光线、背景与构图后，再匹配另外三张。

```text
为工业设备教学软件制作一张设备目录封面。
以我提供的真实设备截图为唯一结构参考。保持设备的轮廓、比例、组件数量、
管路、法兰、护罩、柜门、仪表和材质分区，不新增或删减任何结构。

画面风格：克制的工业产品摄影，石墨灰工作室，柔和大面积主光，
轻微轮廓光，保留黑色金属和深灰漆面的细节，避免高光过曝。
保留原设备已有的橙色或黄色部件，不给设备额外涂装。

构图：4:3，三分之四观察角，完整设备位于中央；主体约占可用画面高度的 70%–78%，
四周留出足够裁切空间，底座、顶部附件、外露接口完整可见。
背景纯石墨灰 #1A1E24，柔和接触阴影，无场景杂物。

不要新增标题、设备编号、参数、中文、英文、水印、图标或 UI 边框。
输出单张 1200×900 PNG。若工具无法忠实保持参考结构，请保留原图设备，
仅处理设备之外的背景；不要重新设计机械结构。
```

按设备补充一句：

- **水泵：** 保留泵体、电机、联轴器护罩、底座和现有管口相对位置，完整呈现横向结构。
- **储罐：** 保留筒体、顶部附件、梯子、仪表和支承，完整呈现高度，不裁掉罐顶或底部。
- **风机：** 保留筒体、叶轮、底座和现有接线盒，入口叶片关系与参考一致。
- **控制柜：** 柜门开合角度与参考一致；若参考为开柜图，保持器件、线槽、端子和走线位置，不重画内部电气结构。

**审核重点：** 外部图片用于教学入口时，结构一致性比“看起来更精致”更重要。发现部件变形、缺失或新增，退回原模型渲染，不把问题图片直接导入工程。

## 3. AI 助手欢迎插图

```text
为工业设备运维教学软件绘制一张简洁欢迎插图。
内容是一块抽象的设备知识卡片、少量机械结构线和一个简洁对话符号。
使用轻微立体感的矢量插画语言，结构清楚，细节适中，适合缩小后显示。

配色：石墨灰、灰白、少量琥珀色 #E8B75C，琥珀色只用于局部重点。
不要人物、拟人机器人、表情、表盘数据、复杂机械细节或密集装饰。
不要文字、数字、品牌、水印、按钮、界面框架。
主体完整，居中，四周留白，透明背景，1024×768 PNG。
不要把透明棋盘格画进图像。
```

这张图只用于尚未开始聊天的欢迎区域。实际对话后应收起，避免占据回答空间。

## 6. 交付前检查

- 每张素材单独导出，文件名稳定、尺寸正确，主体无裁切。
- 缩小到计划展示尺寸后，轮廓仍清楚；不会只在原始大图上好看。
- 四张设备图的角度、光照、背景统一，并与项目中实际模型一致。
- 透明图在深色和浅色背景上都检查一遍，无白边、黑边和棋盘格残留。
- 图片不含按钮、实时数据、说明文字，后续语言和状态变化可由 UI 控制。
- 保留生成工具、日期、提示词、参考图、允许使用范围的说明。原图和审核通过图分开存放。
- 未通过审核的素材留在设计目录，只有通过的最终文件才进入 Unity Assets。

首轮无需购买大型 UI 资源包，也无需等待所有可选插图齐全。优先把页面布局和四张设备封面的统一性做好。
