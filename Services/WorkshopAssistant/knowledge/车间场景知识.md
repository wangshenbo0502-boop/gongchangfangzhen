# 场景定位与数据边界
工业车间设备三维可视化监控与交互巡检系统是 Unity 6 教学演示项目。统一程序 WorkshopPlatform.exe 默认进入 WorkshopDemo.unity，可从“小车装配训练”切换到原 Factory Training 场景，再返回数字孪生平台。左栏包含车间总览、设备学习、实训任务、AI 助手和更多。实训任务内提供小车装配、故障处置和实训复盘，更多内提供资料管理。全部运行参数由 WorkshopSimulation 和 WorkshopDevice 本地模拟，不是传感器采集。不能把官方训练验证通过当作监控系统验收通过。没有真实 PLC、OPC UA 或 MQTT 设备接入。助手只提供解释和操作建议，不执行设备控制。

# 设备台账
生产车间 A 展示共 5 个模型：巡检小车，加上 P-01 循环水泵（离心循环泵）、TK-01 工艺储罐、F-01 车间排风机（轴流风机）、PLC-01 设备控制柜四台受监控设备。小车负责导航与装配实训，不计入四台设备的运行率。储罐、循环泵和控制柜组成靠近仓库作业侧的工艺设备岛，风机位于设备岛外侧，中央下方保留小车检修通道。设备状态为运行正常、已停机或具体故障名称。静态台账不能证明当前状态，当前状态以请求中的场景快照为准。

# 模拟指标
系统约每 0.25 秒采样一次。水泵、风机正常温度在标称 42°C 附近平滑波动；储罐约 25°C，控制柜约 32°C。正常振动约 1.2 mm/s；风机标称转速 980 r/min，水泵 1450 r/min。故障温度、振动与转速依具体工况变化，不能把所有故障解释成超温。预警工况可降速运行，严重工况联锁停机；人工或故障停机后的转速与当前振动为 0。储罐与控制柜不适用转速、振动。泵有出口压力、流量，罐有压力、液位，柜有控制电压、通信质量；只解释设备适用的指标。以上为教学设定，不是工业报警阈值。

# P-01 超温告警
从“实训任务 → 新建课题”选择设备与工况，点击“注入故障”；也可从设备的“故障学习”页点击“开始故障实训”。P-HOT 为泵超温保护，模拟温度约 92°C、保护停机，当前转速和振动为 0。当前泵模型为 P-01；其余三类设备也各有适用故障。每台设备最多一个未处理故障，重复注入受到保护；不同设备可同时告警。ALM-xxx 告警包含对应故障编码、名称、级别和进度。运行数量由实际状态计算，预警不一定减少运行数。

# 多类型故障目录
当前四类设备各有 4 种故障，共 16 个可操作工况。水泵：超温保护、汽蚀、机械密封泄漏、轴承损伤。储罐：超压联锁、罐体泄漏、高液位预警、支座变形。风机：叶轮不平衡、风道堵塞、轴承抱死、叶片裂纹风险。控制柜：柜内散热失效、控制电源欠压、现场总线中断、接点过热。源码仍保留旧输送线和电机目录及对应参考算例，不能据此声称当前车间还展示这些设备。故障机理是预设教学条件，不是自动诊断结论。处理建议以快照告警的 action 为准。

# Abaqus 结果与教学特效
热流线、振动环、漏液、变形轮廓、电气闪烁和堵塞标记均为三维示意，不是应力云图或真实流体计算。可导入真实 Abaqus ODB 导出的指定设备、指定故障、指定实例的时间包络 JSON，回放最大 Mises 应力、最大位移或最高温度。各极值可能来自不同节点或单元，不能当成同一测点，也没有空间网格映射。没有通过校验的 ODB 文件时只运行教学故障模型，不能称为完成 Abaqus 求解。通信中断和控制逻辑也不是有限元直接求解的故障。

# 巡检派发与处理
开始故障实训后打开对应设备工单，工单自动显示设备名称。待巡检时点击“开始巡检”即可派出小车，历史“未派发”对应现在的待巡检。途中可点“查看现场”跟随小车，再点“返回工单”。实际到达后只填故障原因并提交维修，随后点“验收通过”归档。维修提交即释放小车，故障保留到验收通过。验收驳回回到待巡检，重新到场复查。

# 无法派发、无法确认处理
小车一次只能执行一个任务。等待其他工单的小车释放后再开始巡检。目标巡检点必须有完整的可达路径。机器人到达目标且任务与当前工单一致后才能提交维修。手动驶离维修点会撤销到达状态，返回后才能继续；“恢复自动巡检”继续原任务。

# 复位与记录
验收通过后，设备恢复故障发生前的运行或人工停机状态，实训复盘显示设备名称、故障原因与系统生成的时间和工单状态。“会话 → 结束并重置”清空本次工单和记录并恢复演示初始状态。业务记录保存在当前场景会话，Docker 数据库保存知识文档与向量索引。

# 故障参考分析与整机观察
故障分析资源共保留 21 组完好/缺陷 scikit-fem 参考件，其中 14 组对应当前四台设备。支持应力、位移、应变、主应力、温度、热通量、剖切、等值线、测点及 CSV/截图导出。参考件使用名义几何和线弹性或稳态热条件，不是整机实测或 Abaqus 结果。当前 PLC-LOW、PLC-COMM 没有 FEM 参考件。渐进开裂和整机 18 秒损坏演化是预设运动学示意，不是求解得到的裂纹扩展。设备工作区的“拆装”和故障学习的“查看演示”可观察当前四类设备、拆分部件、故障近景和尺寸导出。2026-11-12 当前平台已接入精细离心泵和轴流风机，可通过“视图 → 在独立展示器中打开”打开配套独立展示器；泵为 12 总成，风机为 11 总成。储罐与控制柜的新版 Blender 模型尚未替换平台运行模型，独立展示器画面不能当作平台接入证明。

# 知识导入
知识导入支持标题与正文，以及 UTF-8 MD/TXT 本机文件。服务端按内容哈希去重、分片、向量化并保存资料，可供后续 AI 检索引用。知识库就绪不等于 DeepSeek 密钥有效；本地参考资料不等于在线模型生成的回答。索引不可用、密钥鉴权失败应如实显示错误。

# 场景观察
点击设备台账会选中并聚焦设备，三维点选会同步设备详情。左键拖拽或右键拖拽旋转，滚轮缩放，中键平移；总览恢复整体视角，巡检跟随跟随机器人，屋顶开关控制顶棚显示。设备启停按钮仅改变选中设备；故障设备不能通过普通启动解除，需完成巡检处理流程。

# 场景维护建议
针对泵超温，可在演示讲解中建议检查冷却条件、泵入口堵塞、负载和轴承状态；这些只是常见检查方向，项目没有提供足以确定真实根因的传感器或维修数据。真实设备检修须按现场规程与设备厂家手册执行。不要把模拟温度阈值用于真实工厂控制。
