# P-01 循环水泵故障速查
依据 2026-11-12 工程 WorkshopFaultCatalog、WorkshopSimulation 与 README 整理。仅供本系统教学问答；下面描述的是预设故障机理和检查建议，不代表现场检测结论。当前故障、指标和进度以本次 Unity 快照为准。

## P-HOT 超温保护：为什么水泵停转
适用设备 P-01 循环水泵。预设机理是冷却或润滑异常使泵体温升，触发严重告警和保护停机；教学故障温度约 92 摄氏度。停机后的当前转速和振动为 0，不能把目录中的故障振动参数说成当前实测值。演示建议检查冷却、润滑与负载情况，经报修、派工、实际到场、维修提交及使用方验收后关闭。普通“启动设备”不能消除故障。

## P-CAV 汽蚀：振动大且流量下降
适用设备 P-01，属于预警，不自动保护停机。预设机理为入口供液不足或压力降低，引起汽泡形成与溃灭；症状是高频振动、出口压力和流量下降，转速降低。演示建议停泵检查入口供液、过滤器和吸入条件，再记录检查与处理结果。不能仅凭振动大就排除轴承损伤，也不能把模拟参数用于确定真实汽蚀余量。

## P-SEAL 机械密封泄漏：为什么泵旁有漏液
适用设备 P-01，严重故障，保护停机。预设机理为密封副磨损或损坏造成介质外泄；教学画面在密封区域显示漏液。演示建议停泵并隔离介质，检查维护密封，完成试漏后填写维修记录，再由使用方验收。三维漏液是教学特效，不能给出真实泄漏量或断言真实密封已损坏。

## P-BEAR 轴承损伤：如何与汽蚀区分
适用设备 P-01，属于预警，可降速运行。预设症状是轴端摆振、摩擦温升增加、出力下降；目录教学振动参数为 7.2 mm/s。故障预览“看轴承”可暂时隐藏轴承壳和护罩，显示原轴承圈、滚珠和轴；关闭时恢复。外圈滚道局部在运行时副本上预设最多 1 mm 材料损失，青色/橙色线标记完好与异常区域，可单独关闭；这是教学几何，未求解接触、剥落发展或轴承寿命。演示建议停泵检查轴承、润滑与对中。汽蚀侧重入口供液、压力和流量，轴承损伤侧重轴端、润滑与对中；这只是本演示的辨析线索。优先读取快照 faultCode 和告警 action，不从单个模拟数值推断真实根因。

## P-01 如何做一组正常与故障对照
在正常运行时记下转速、振动、出口压力和流量，再注入 P-CAV 或 P-BEAR。模型中 P-CAV 的转速约为额定的 85%，压力和流量约降至正常值的一半。P-BEAR 的转速约为额定的 80%，压力和流量约为正常值的四分之三，并有更高的振动和温升。以当前快照数值为准。若 P-HOT 或 P-SEAL 已联锁停机，两个工况的转速、当前振动、出口压力和流量都为零，此时用故障编码及热点或漏液位置区分。

## 2026-11-16 新增四案例

- P-ALIGN 联轴器不对中：联轴器轴线对照与局部振动是教学示意。检查软脚并对中，复核对中记录及同转速振动；辅助线偏移不属于实测轴线。
- P-INLET 入口受阻：在原吸入法兰的实际孔径内新增教学滤网和预设扇区受阻物，配合可关闭的参考/异常流向标记及教学流量下降。滤网是新增教学插入件，不代表原设备已装该过滤器，受阻范围与流量没有流阻求解关系，也不据此认定已经汽蚀。核对过滤器、阀位与供液条件，维护后同转速复测。
- P-IMPELLER 叶轮磨蚀：通过“看叶轮”暂时让开原蜗壳、入口盖和前盖，在原叶片实例副本上显示第一叶片外缘预设最多 2 mm 的径向磨蚀；内侧大部分顶点及原资产保持不变，回到完好进度或退出时恢复。读数及出力变化为教学设定，未计算冲蚀速率、质量损失或水力性能。专业检查修复并校平衡，复核出力。
- P-DRY 缺液空转：对照供液丢失与密封升温，不能画成壳体断裂。恢复灌泵条件并检查密封，记录供液、试漏与温升复核。

青色辅助线表示参考条件，橙色表示异常条件，可在视图的教学辅助显示中关闭。所有新增指标均为教学设定；无真实结果时不提供应力、寿命或真实漏率。
