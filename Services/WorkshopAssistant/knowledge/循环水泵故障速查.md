# P-01 循环水泵故障速查
依据 2026-11-12 工程 WorkshopFaultCatalog、WorkshopSimulation 与 README 整理。仅供本系统教学问答；下面描述的是预设故障机理和检查建议，不代表现场检测结论。当前故障、指标和进度以本次 Unity 快照为准。

## P-HOT 超温保护：为什么水泵停转
适用设备 P-01 循环水泵。预设机理是冷却或润滑异常使泵体温升，触发严重告警和保护停机；教学故障温度约 92 摄氏度。停机后的当前转速和振动为 0，不能把目录中的故障振动参数说成当前实测值。演示建议检查冷却、润滑与负载情况，经报修、派工、实际到场、维修提交及使用方验收后关闭。普通“启动设备”不能消除故障。

## P-CAV 汽蚀：振动大且流量下降
适用设备 P-01，属于预警，不自动保护停机。预设机理为入口供液不足或压力降低，引起汽泡形成与溃灭；症状是高频振动、出口压力和流量下降，转速降低。演示建议停泵检查入口供液、过滤器和吸入条件，再记录检查与处理结果。不能仅凭振动大就排除轴承损伤，也不能把模拟参数用于确定真实汽蚀余量。

## P-SEAL 机械密封泄漏：为什么泵旁有漏液
适用设备 P-01，严重故障，保护停机。预设机理为密封副磨损或损坏造成介质外泄；教学画面在密封区域显示漏液。演示建议停泵并隔离介质，检查维护密封，完成试漏后填写维修记录，再由使用方验收。三维漏液是教学特效，不能给出真实泄漏量或断言真实密封已损坏。

## P-BEAR 轴承损伤：如何与汽蚀区分
适用设备 P-01，属于预警，可降速运行。预设症状是轴端摆振、摩擦温升增加、出力下降；目录教学振动参数为 7.2 mm/s。演示建议停泵检查轴承、润滑与对中。汽蚀侧重入口供液、压力和流量，轴承损伤侧重轴端、润滑与对中；这只是本演示的辨析线索。优先读取快照 faultCode 和告警 action，不从单个模拟数值推断真实根因。
