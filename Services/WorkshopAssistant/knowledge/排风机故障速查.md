# F-01 车间排风机故障速查
依据 2026-11-12 工程 WorkshopFaultCatalog 与 README 整理。F-01 是轴流风机，当前平台精细模型按 11 个总成展示。拆装动画、故障特效和模拟监控值均不构成真实设备检修结论；故障以本次快照为准。

## F-IMBAL 叶轮不平衡
设备 F-01，预警，降速运行。预设机理是叶轮积灰或质量偏心产生周期离心载荷，症状为叶轮摆振、风量下降。演示建议断电检查积灰和叶片，清洁并校平衡后完成维修验收。系统没有提供真实动平衡检测数据，不能声称已测得不平衡质量或已经校平衡。

## F-BLOCK 风道堵塞
设备 F-01，预警，不自动保护停机。预设机理是风道阻力增大，症状为转动迟缓、风量显著下降。演示建议断电清理风道与滤网、检查风阀。与叶轮不平衡相比，本工况教学重点是通风阻力和低风量；不能因为设备仍转动就说故障已解除。

## F-BEAR 轴承抱死
设备 F-01，严重故障，保护停机。预设机理是润滑失效或轴承损坏使转子锁止，症状为轴承热点、风机停转。目录教学温度约 98 摄氏度；停转后的当前振动和转速为 0。演示建议隔离电源，检查轴承和润滑，维护后填写维修记录，等待使用方验收关闭。

## F-CRACK 叶片裂纹风险
设备 F-01，严重故障，联锁停机。预设机理是叶片局部刚度降低和疲劳失效风险，画面显示叶片警示轮廓。演示建议停机隔离，检查叶片及连接，完成专业检查后再记录和验收。裂纹、损坏演化是预设教学动画，不能给出真实裂纹扩展速度、寿命或应力结论。
