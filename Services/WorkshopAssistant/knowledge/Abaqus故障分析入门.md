# Abaqus 与故障分析入门

## Abaqus 是什么，和这个项目有什么关系
Abaqus 是用来做有限元分析的工程软件。有限元可以理解为把零件划成许多小块，给定材料、载荷和固定方式，再计算哪里受力较大、移动较多或温度较高。这个项目的“深入分析”用内置 scikit-fem 参考件展示这些结果。项目另外提供 Abaqus 结果接入接口，可读取外部求解后的 ODB 包络数据。打开“深入分析”时，平台会读取已有参考结果。

## 从哪里打开故障分析，三个按钮分别做什么
进入“设备学习 → 故障学习”，上方先选设备，再选工况。想看彩色云图，点“深入分析”。想看三维设备哪里发热、漏液、摆振或出现裂纹示意，点“查看演示”。想触发车间告警并派小车，点“开始故障实训”。仅看演示和深入分析时，可以在未创建工单的情况下学习故障。当前配有参考算例的工况可以直接查看，无需安装 Abaqus。

## 一张云图先看哪三处
第一，看左上角标题和来源，确认正在看哪个设备、故障和部件。第二，看左侧下拉项和底部色标，确认颜色对应的是应力 MPa、位移 mm，还是温度 °C。颜色表示这个量在当前色标上的大小，是否超限还要看适用的限值。第三，在同一显示量和同一载荷或热源倍率下，切换“完好 / 基准”和“故障 / 缺陷”，同时比较峰值数字和高值区域。需要查材料、载荷和约束时，打开“工具 → 模型说明”。

## 应力、位移、温度分别在说什么
Mises 应力把复杂受力合成一个用于比较的等效应力值，单位 MPa。读图时先看哪里更集中，判断材料是否可能屈服还要结合材料和适用准则。位移用 mm 表示，位移模长是一个点移动了多远；“变形显示”可把形状夸大，具体距离读位移值。温度用 °C 表示，表示参考件某处的计算温度；热流密度用 W/m² 表示，可用来观察热量传递集中在哪里。结构算例主要看应力和位移，热算例主要看温度和热流密度。

## 跟着看一遍 P-01 水泵超温
选 P-01 循环水泵和 P-HOT 超温保护，点“深入分析”。选择“温度 / °C”，保持热源倍率 1.00×，切换“完好 / 基准”和“故障 / 缺陷”。泵出口管参考件的峰值温度约从 27.87°C 升到 35.58°C，相差 7.71°C。两种模型热源相同，故障模型的散热能力降低，因此温度更高。车间总览里的约 92°C 是 P-HOT 故障注入后整台泵的教学监控值；云图的 35.58°C 属于给定条件下的出口管参考件。

## 跟着看一遍 F-01 叶片裂纹风险
选 F-01 车间排风机和 F-CRACK 叶片裂纹风险，点“深入分析”。在载荷倍率 1.00× 时切换完好与缺陷件，最大单元均值 Mises 应力约从 10.20 MPa 升到 18.94 MPa，最大位移约从 0.252 mm 升到 0.302 mm。用“工具 → 观察与测量 → 极值定位”找高值区域。可用一句话解释：在同一参考载荷下，预设缺口使参考件的峰值应力和位移上升。开裂动画里的时间点来自预设脚本，判断真实裂纹会不会扩展或还能用多久需要额外分析。

## 界面上的来源怎样读
“查看演示”的三维效果用于说明故障现象。“深入分析”页显示“真实数值求解 / 参数化参考件 / 非 Abaqus”，对应本项目内置的 scikit-fem 结果。真正的 Abaqus 结果需要已有 ODB 文件，导出并导入匹配设备和故障的 JSON 后，运行时来源才会标记为“Abaqus ODB 包络回放”。当前工程未随附真实 ODB 结果。PLC-LOW 欠压和 PLC-COMM 现场总线中断没有内置有限元参考件，回故障页看电压和通信质量更直接。

## 有自己的 Abaqus 结果时怎么接入
ODB 是 Abaqus 求解生成的结果数据库。项目的导出脚本按分析步、装配实例和工况提取每个时间点的最大 Mises 应力、最大位移或最高温度，并转换单位。用 Unity 编辑器的 `Tools/Workshop Demo/Import Abaqus Fault Result` 导入导出的 JSON，再重新注入匹配的设备故障来加载。故障运行状态及助手快照会记录已加载的数据来源，“深入分析”的彩色云图仍读取内置参考件。技术步骤见 [Abaqus 导入说明](../../../Tools/Abaqus/README.md)。

## Abaqus 的包络能回答什么
“包络”是每个时间点在选定区域内分别取各指标的最大值。它可以回答“这一刻该区域的最大应力是多少”和“最大位移随时间怎么变”。应力最大和位移最大的地方可以不同。当前导出格式保留时间和极值，未包含节点位置或整机网格。若要看 ODB 本身的应力分布或最大值位置，需要回到 Abaqus 查看原结果。
