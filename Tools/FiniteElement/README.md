# 参考件故障有限元分析

统一版入口为当前工程 `Build/WorkshopPlatform/WorkshopPlatform.exe`，默认进入数字孪生平台。
在“故障分析”选择设备和工况，点击“有限元分析”。不需要先注入告警。
旧 `WorkshopCombined` 构建按用户要求保留，不覆盖。下文日期描述迁入源码的历史功能，当前整合验证另见 Evidence。

## 可见的物理变化

- 完好／故障切换显示实际不同的缺口或壁厚网格，缺陷尺寸列在左侧。叶片裂口是有限宽开口缺口，不是已求解的裂纹扩展。
- 管件和罐壁默认半剖，显示内部局部减薄；可旋转、缩放和关闭半剖。半剖是观察方式，不是新增损伤。
- 应力、位移、温度使用基准与故障共用的定量色标；单位分别为 MPa、mm、摄氏度。
- 最大单元平均应力、最大位移、峰值温度与变化率取自求解结果；点击网格显示对应位置探针值。
- 变形放大与真实位移数值分开。放大倍数设为 1 即真实比例。载荷倍率仅按线性方程缩放，不能作为非线性、接触或裂纹增长求解。

## 2026-11-10 精细场量与交互

- 叶片裂口两工况采用细网格：完好 17,010、故障 18,576 个二次四面体；柜内散热板使用 17,010 个一次四面体。其他算例保持各自网格，不宣称所有网格尖角应力收敛。
- 结构共 16 种场量：Mises、位移模长、三向位移、六个对称应力分量、三个主应力、平均正应力、等效偏应变。温度算例另有温度和热流密度。主应力由单元平均应力张量特征值计算；等效偏应变按 Mises/(3G) 换算，不是塑性应变。
- 共用色标支持正负分量。可切换原始单元和面积加权节点平均显示；平均仅用于显示，数值比较和探针应力保持原始单元值，不能用平均云图证明精度提升。
- 显示长度、截面原尺寸、载荷/内压、固定端、当前场量表面极值、应变能、体积、三向反力与合力、平衡误差。热学显示热功率、散热功率、节点温度统计与表面最大单元热流。
- 整机窗口复用所选设备的原始网格及材质，只复制渲染器，不复制业务脚本。拖动旋转、滚轮缩放、“拆分观察”查看原有美术部件。它不代表真实装配工艺、失效解剖或实际 CAD 有限元配准。
- 缺口和减薄工况提供独立局部相机，直接观察同一求解网格。滚轮放大局部，点击近景定位主视口；近景不另造缺陷或计算结果。
- 主窗口支持旋转、右键拖动平移、缩放、正/俯/侧视、复位、极值定位、移动剖切面、环绕观察和最多三个测点。两点距离取未变形几何，单位 mm；不是放大变形后的屏幕距离。
- 载荷往复在已有线性解上显示准静态倍率，不求解惯性、疲劳、瞬态温度或裂纹扩展。开启时仍显示当前倍率及变形放大。
- “导出测点”写 CSV，包含工况、倍率、坐标、已求解的局部应力/位移或温度及数据 SHA256；未求解的物理量留空。“保存快照”保存当前屏幕。路径在 Unity `Application.persistentDataPath/AnalysisExports`，界面反馈具体文件位置。

## 模型与来源

21 个参考工况，每个均包含基准与故障两个实际数值解。8 台设备复用对应类别。
输送梁、轴套、泵管、罐壁、叶片、支座、柜内散热板都是参数化参考件，不是展示 FBX 转成的真实设备 CAD。
材料为假设常数钢材：E=210 GPa，ν=0.30，k=45 W/(m·K)。几何、载荷、边界、假设机制与局限随每个结果保存并显示。

结构：scikit-fem 二次四面体、三维小变形线弹性，端面固定，指定端面力或内壁压力。应力先取单元平均张量，再算 Mises；不伪造平滑后的峰值。
温度：一次四面体稳态导热、给定局部体热源和全表面对流，环境 25°C。热功率是建模输入，不是由缺相、电流或接触电阻自动预测。

`CV-SLIP`、`PLC-LOW`、`PLC-COMM` 不提供 FEM 结果，仍由现有教学过程模型演示。
汽蚀工况仅计算假设压力包络的结构响应；密封/罐体泄漏仅展示缺陷承载影响，不计算汽蚀流场或漏率。
没有求解塑性、复杂接触、裂纹扩展、疲劳寿命、振动频谱或失效概率。不应据此给真实设备作检修或安全结论。

## 可复现与校核

```powershell
python -m pip install -r Tools/FiniteElement/requirements.txt
python -u Tools/FiniteElement/generate_reference_cases.py
python Tools/FiniteElement/verify_enriched_fields.py
```

结果写入 `Assets/StreamingAssets/WorkshopAnalysis/`，Unity 不依赖 Python 运行。
校核报告写入 `Evidence/fem-reference-verification-20261109.json`，包括解析拉伸、悬臂梁对照、反力平衡、热平衡和裂口粗细网格位移敏感性。
最初一次单元薄梁过硬的结果保留为 `Evidence/fem-reference-initial-linear-tet-20261109.json`，不作为最终数据。
网格位移敏感性不能证明尖角局部应力收敛；界面明确保留该限制。
结果 SHA256 在界面及报告中提供，便于核对同一批数据。
新增 `Evidence/fem-enriched-verification-20261110.json` 校验保存文件的应力不变量、主应力、热流/功率平衡、裂口剩余厚度及罐壁减薄尺寸。细网格不改变参考假设与实际设备未标定的边界。

## 与 Abaqus 的关系

本机本轮未执行 Abaqus；内置数据不称为 Abaqus 结果。
`AbaqusInputs/` 包含所有机械参考件两工况的 C3D10 `.inp`，采用相同网格、材料、固定端和等效节点载荷，可在具备许可证的 Abaqus/Standard 中独立复算。

```powershell
abaqus job=F-CRACK-fault input=Tools/FiniteElement/AbaqusInputs/F-CRACK-fault.inp interactive
```

这些输入文件在本机未通过 Abaqus 验证，不能宣称跨求解器一致性已经通过。
真实 ODB 的标量包络导出与设备绑定仍见 `Tools/Abaqus/README.md`；该旧导入通道不导出全场网格，不能替换本分析视图为“Abaqus 全场结果”。
