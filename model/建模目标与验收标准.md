> 本文件是交给建模执行方（人或 GPT + Blender 脚本）的**施工规范**，不是愿望清单。
> 带数字的条目都应能被执行、被脚本检查、被截图证明。
> 修订：2026-11-10。取代同日原始版（已备份为 `建模目标与验收标准-20261110-原始版.md`）。
> 适用范围：离心泵、立式储罐、轴流风机、电气控制柜四类新模型；现有巡检小车保留不动，仅作为质量参照。

### 1.2 三条必须遵守的隐藏约束

**（a）模型包围盒就是导航障碍物。**
生成器对每台设备的渲染包围盒加一个 BoxCollider 并烘焙进 NavMesh。模型做大 20%，就实打实挤掉 20% 的巡检通道。尺寸必须按第 2 章执行，不能靠 Unity 里缩放去凑。

**（b）巡检点在设备中心前方 1.8 m。**
生成器写死：
```
inspectionPoint = device.position + (0, 0, z > 0 ? -1.8f : +1.8f)
```
也就是说巡检点距设备中心 1.8 m。**若设备前半深超过 1.2 m，机器人会站进模型内部，派发路径检查失败。** 因此四台设备沿朝向方向的前半深一律 ≤ 1.2 m。储罐靠支腿内收与封头收窄满足；若确实需要更大投影，必须同时修改生成器为"包围盒外扩 0.7 m"并重新烘焙导航，不能只改模型。

**（c）生成器按名字找节点，逐字匹配。**
- 转动件：`<modelName>_rotor` 或 `<modelName>_drum`，找不到就没有转动动画。
- 状态灯：renderer 名同时含 `lamp` 和 `lens`。
具体名单见 3.2 节。

## 2. 坐标、单位与尺寸

### 2.1 全局约定

- 单位 **米**。Blender 场景 `Unit System = Metric`，`Scale = 1.0`，导出不缩放。
- Blender Z 向上，Unity Y 向上。FBX 导出勾 `Apply Transform`，Up `Y`，Forward `−Z`。导入 Unity 后设备正面朝 **+Z**。
- 每个设备根节点的原点在**底面中心**：`min(Z) = 0`，X/Z 包围盒中心为 0。这样生成器的落地对齐才不会把模型埋进地板。
- 导出前 `Object → Apply → All Transforms`，缩放必须为 1。非均匀缩放会同时破坏 Unity 碰撞体、描边和法线。
- 旋转件枢轴必须落在**真实转轴**上，不能用包围盒中心顶替。叶轮、轴、柜门铰链都按这条办。

### 2.2 设计尺寸

| 设备 | 宽 X | 深 Z（前 / 后） | 高 Y | 依据 |
| --- | --- | --- | --- | --- |
| 离心泵 | 1.90 | 1.00（0.50 / 0.50） | 1.35 | 两泵 3 m 间距留 1.1 m 检修口 |
| 立式储罐 TK-01 | 3.00 直径 | 3.00（旧包络；附件安装包络另测） | 约 5.86 | 用户 2026-11-12 指定总高；通道净空仍需接入验证 |
| 立式储罐 TK-02 | 2.16 直径 | 2.16（1.08 / 1.08） | 3.60 | 复用同一 `.blend`，`Object → Scale` 后 Apply，等效 0.72 等比 |
| 轴流风机 | 1.60 | 1.60（0.80 / 0.80） | 1.80 | 风筒轴线沿 X |
| 电气控制柜 | 1.20 | 0.65（0.325 / 0.325） | 2.00 | 柜门朝 +Z，全开也不越 1.2 m |

容许偏差 **±3%**（长宽高分别计）。超差必须在自检报告里写原因，否则视为不合格。

| 离心泵 | 120k | 蜗壳+叶轮 45k，电机 25k，紧固件 20k |

## 3. 命名与层级

### 3.1 根节点与八个组件组

```
<modelName>                       ← FBX 根对象，名字必须精确
├── <ID>_00_Base
├── <ID>_01_<Group>
├── ...                            ← 共 8 组，编号 00–07 连续
└── <ID>_07_<Group>
```

- `<modelName>` 只允许：`water-pump`、`silo`、`pressure-tank`、`industrial-fan`、`electrical-cabinet`。
  这是生成器拼路径 `External/Grab3D/<modelName>/<modelName>.fbx` 用的，改名就加载不到。
- `<ID>` 取 `PMP` / `TNK` / `FAN` / `CAB`。
- 恰好 8 个组件组。螺栓、铭牌、垫片只能放在组内部，不得单独成组。
- 组内子对象用 `<Group>_<Part>_<NN>`，例如 `PMP_04_Volute_PumpBody_Flange_Inlet`。

### 3.2 代码识别名（错一个字功能就没了）

| 用途 | 必须叫 | 本地旋转轴 | 说明 |
| --- | --- | --- | --- |
| 泵转子 | `water-pump_rotor` | Z | 轴+叶轮+联轴器整体，枢轴在轴心 |
| 储罐液位体 | `silo_drum`、`pressure-tank_drum` | — | 可放在组件组内 |
| 风机叶轮 | `industrial-fan_rotor` | Z | 枢轴在风筒轴线 |
| 状态灯 | renderer 名同时含 `lamp` 与 `lens`，如 `cabinet_lamp_lens` | — | 至少控制柜提供 |

`WorkshopDevice` 运行时执行 `rotor.Rotate(rotorAxis, ...)`，`rotorAxis` 固定为 forward（本地 +Z）。所以**转子/叶轮的本地 Z 轴必须与真实转轴重合**，Blender 里先对准再导出，导入后不要再手工旋转，否则会绕错轴甩出去。

### 3.3 层与标签

- 全部网格默认层，**不要**设成 `Outline`（第 8 层）。第 8 层只给描边 renderer 用，模型误入会被额外描边。
- 不添加任何 MonoBehaviour、Camera、Light、Empty 动画数据到 FBX；灯与相机留在 `.blend` 里做渲染预览用，导出时排除。

## 5. 建模方法与质量回路

### 5.1 统一制作流程（每台设备按此顺序）

1. **块面（Blockout）**：只用长方体/圆柱建整体比例，导出线框图对比第 2.2 节尺寸。**比例不对不进入下一步。**
2. **主结构**：蜗壳/封头/风筒/柜体用 `Loop Cut` + `Subdivision`（1–2 级）或非破坏性 `Bevel` 修改器，轮廓圆度用**至少 48 段**（直径 >1.5 m 用 64 段）。
3. **壁厚**：钣金与筒体统一用 `Solidify` 修改器，厚度按图纸：柜板 1.5 mm、筒体 8 mm、法兰 12 mm、护罩 1.0 mm。应用前检查法线朝外。
4. **硬表面细节**：所有外露加工边 `Bevel`（宽度 0.5–2 mm，段数 2–3）。**禁止用 `Shade Smooth` 掩饰硬边**：角度 >30° 的边必须用 Auto Smooth 或标记 Sharp。
5. **紧固件与开孔**：螺栓用六角头+垫圈+螺母三段式实例；开孔用 Boolean 后清理 n-gon，再 `Triangulate` 局部。
6. **UV**：主结构用 `Smart UV Project`（角度 66°）后手工对齐；大平面单独展 UV，保证贴图不拉伸（任意面 UV 拉伸比 ≤ 1.25）。
7. **材质与贴图**：按 5.3 节。
8. **命名与层级**：按第 3 章，逐个核对。
9. **法线与法线贴图**：全部 `Recalculate Outside`；导入前用 Blender 的 `Face Orientation` 检查蓝色朝外。
10. **导出**：按 7.1 节参数，导出后立即在 Unity 里看。

### 5.2 比例与"看起来像真的"具体条款

- 圆形容器**不能用低段数圆柱**：直径 3 m 的储罐圆周至少 64 段，肉眼贴近 1.5 m 无明显折线。
- 两件相接处**必须有装配间隙**：法兰对接留 0.2–0.5 mm 缝或加垫片，不能共面 z-fighting。
- 螺栓**不得悬空**：螺栓头必须压在法兰面或垫圈上，螺纹段进入螺孔。
- 焊接、铸件分型、冲压痕用**法线贴图**表现，不用建模堆。
- 铭牌朝向与人视角一致，文字不能镜像、不能上下颠倒。
- **反例判定**：如果去掉贴图后仍能看出设备类型与主要结构，说明几何合格；如果去掉贴图就变成一堆圆柱和方块，判定不合格，回到第 2 步。

### 5.3 材质与贴图规范

参照小车的 5 通道 PBR 与 4096² 贴图水准，但按自有材质单位建库。

| 材质类 | Metallic | Roughness | 贴图 |
| --- | --- | --- | --- |
| 喷漆钢（泵/风机） | 0.0 | 0.45–0.60 | BaseColor + Normal + Roughness |
| 铸件（蜗壳、壳体） | 0.0–0.05 | 0.65–0.80 | BaseColor + Normal（砂型颗粒） |
| 机加工金属（轴、法兰面） | 1.0 | 0.20–0.35 | 各向异性可选 |
| 拉丝钢板（控制柜） | 0.9 | 0.30–0.40 | 拉丝方向统一沿 X |
| 镀铬（活塞杆、铭牌边） | 1.0 | 0.05–0.12 | — |
| 橡胶（减振垫、密封） | 0.0 | 0.85–0.95 | Normal 细纹 |
| 铜（母线、接地排） | 1.0 | 0.30–0.45 | — |
| 绝缘塑料（端子、线管） | 0.0 | 0.55 | — |
| HMI 屏 | 0.0 | 0.08–0.15 | 自发光贴图 |

- 贴图分辨率：主设备 2048²，细节件 1024²，小件 512²。**不要全部 4096²**，会拖垮场景加载。
- 金属粗糙度必须有**非均匀变化**（用噪声或打磨方向遮罩），整体单一数值会显塑料感。
- 颜色：设备主体用工业灰 `#6E7478`、蓝灰 `#3F5866`、安全黄 `#E8B21C`；**不使用重度锈蚀**来遮掩建模缺陷。
- 所有材质用 URP Lit，纹理 sRGB：BaseColor 开、Normal 关、Metallic/Roughness 关。

## 6. 故障变形与开裂网格规范

保留"逐渐形变 → 起裂 → 扩展 → 张开分离"的表现，**不允许退化为贴图线条或整体弯曲**。

### 6.1 必须存在的四类变形体

| 设备 | 变形区域 | 对应故障码 | 形态 |
| --- | --- | --- | --- |
| 储罐 | 筒壁局部（含真实厚度） | `TK-PRESS` | 外鼓 8–25 mm，起裂后开口分离 |
| 储罐 | 支腿/底板 | `TK-SUPPORT` | 屈曲侧倾 ≤ 6° |
| 风机 | 一片工作叶片 | `F-CRACK` | 叶尖偏移 + 叶根裂纹扩展 |
| 泵 | 密封腔与轴系 | `P-SEAL`、`P-BEAR` | 密封面位移 + 渗漏面 |

电气故障（`PLC-*`）用变色、指示灯与屏幕内容表现，**不制造结构断裂**。

### 6.2 网格做法

1. 变形区域单独切出一块**加密网格补片**（边长 20–40 mm，边界与周围顶点焊接，不留缝）。
2. 变形补片同时输出三个形态：`_intact`、`_bulged`、`_opened`，通过 Shader 顶点位移或 BlendShape 线性插值。
3. 开口必须有**内表面**（同一补片挤出 6–10 mm 厚度，内含暗色内壁材质），完好时闭合不可见。
4. 裂纹沿网格边生长，不是贴一条贴图线。边界锯齿用 0.5 mm 倒角平滑。
5. 顶点位移方向逐点记录，导出 CSV 供第 6.3 节校验。

### 6.3 尺寸必须与几何一致

界面上显示的开口宽度、形变幅值、裂纹长度、未裂剩余长度、局部厚度，必须由**同一份顶点数据**算出：

- 开口宽度 = 开口两侧对应顶点的实际距离。
- 形变幅值 = 变形顶点相对完好位置的位移模长最大值。
- 裂纹长度 = 沿裂纹路径的边长累加。
- 无对应量时显示"不适用"，**不得填 0 冒充**。

材料值可用公开典型值并注明来源，但要区分四类数字：几何实测、材料参考、简化演化设定、有限元参考解。**未经求解不得标注为 Abaqus 断裂结果。**

## 8. 尺寸与几何自检（可脚本化）

以下项建议用 Blender Python 或 Unity Editor 脚本自动检查，结果写入 `reports/<modelName>.md`。

| 编号 | 检查项 | 判定 | 建议实现 |
| --- | --- | --- | --- |
| G1 | 根节点原点在底面中心 | `abs(minZ) < 0.005`，`abs(centerX) < 0.005` | 遍历 `bpy.data.objects` 世界包围盒 |
| G2 | 缩放为 1 | 所有对象 `scale ≈ (1,1,1)` | 同上 |
| G3 | 尺寸符合 2.2 | 宽/深/高偏差 ≤ 3% | 包围盒对比表 |
| G4 | 八个组件组 | 名称匹配 `<ID>_0[0-7]_` 且恰好 8 个 | 正则匹配顶层子对象 |
| G5 | 无零厚度面 | 统计 `非流形边` = 0 或已记录 | `bmesh` 检查 |
| G6 | 法线朝外 | 无负体积对象 | `bpy.ops.mesh.normals_make_consistent` 后校验 |
| G7 | 面数 | 单台 ≤ 2.3 节上限 | `len(mesh.polygons)` 三角化后计 |
| G8 | UV 拉伸 | 任一面积比 ≤ 1.25 | UV 面积对比 |
| G9 | 枢轴位置 | 转子轴心误差 ≤ 2 mm | 与设计轴坐标比对 |
| G10 | 代码识别名存在 | `water-pump_rotor` 等按 3.2 节 | 名称精确匹配 |
| G11 | 无孤立/游离小件 | 每个对象属某个组件组 | 遍历父级链 |
| G12 | 包围盒不越 1.2 m 前半深 | `maxZ − centerZ ≤ 1.2` | 与 1.2(b) 条对应 |

### 8.1 视觉验收（必须人眼确认）

自动检查通过不等于好看。每台至少交三张图并逐张确认：

1. **整机 3/4 视角**，背景中性灰，能看到铭牌与主要管路。
2. **拆开状态**，八组分离且方向正确，无穿插、无悬空。
3. **局部近景**：泵的叶轮与蜗壳流道、罐的人孔与壁厚、风机的叶片扭角、柜内的导轨与线束。

## 10. 制作顺序与优先级

1. 先建**统一材质库、倒角规范、紧固件库、铭牌模板**（四台共用），这是质量下限。
2. 做**离心泵**：零件最少、结构最典型，用来验证整套流程与脚本检查。
3. 泵通过后做**轴流风机**（叶片扭角是难点，单独验证）。
4. 再做**立式储罐**（尺寸最大，重点验证壁厚与导航不阻挡）。
5. 最后做**电气控制柜**（内部元件最多，重点验证层级与线束）。
6. 全部通过后统一接入 Unity、重建场景、回归巡检与双分辨率。

每台设备完成后**停下来交付一次**，不要四台一起做完再验收。
